Download

OmniaCMDs runs on Windows 10 and 11. Nothing is installed: unpack the folder where you like, even on a USB stick.

1.0.0

Windows 10 and 11 · GNU GPL v3

Get the release

Run the executable

Download the archive, unpack it anywhere, and run OmniaCMDs.exe. Nothing is written outside the folder you chose.

Run from source

You need Python 3.11 or later and these packages:

pip install PyQt6 ruamel.yaml cryptography keyboard pynput pyperclip pyautogui pygetwindow pytesseract pillow

Then start it with pythonw main.pyw.

First run

The app writes its configuration in config/ the first time it starts. Delete any of those files and a fresh copy appears on the next start, so you can always get back to a working setup.

Reading text from the screen

The tesseract command needs Tesseract OCR installed separately, with the language packs you want. Point the app at tesseract.exe in Settings.
